## 一、MySQL 最初是用什么语言写的？

### ✅ 核心答案

**MySQL 最初几乎是 100% 用 C 写的。**

- 时间：**1995 年左右**
    
- 作者：**Michael “Monty” Widenius**
    
- 目标：**快、简单、能跑在各种 Unix 上**
    
- 当时的理念非常极端：
    
    > _Performance first, simplicity over purity_
    

为什么是 **C 而不是 C++**？

- 90 年代 C++ 还很不成熟
    
- C 在 **系统层、内存控制、跨平台** 上更稳
    
- MySQL 追求的是：
    
    - 极低开销
        
    - 手动内存管理
        
    - predictable behavior（可预测性能）
        

👉 直到今天：

> **MySQL Server 核心依然是 C + 少量 C++**

---

## 二、最早的 MySQL 是怎么来的？

### 1️⃣ 原型阶段（1993–1995）

Monty 当时在做一个内部项目，需要：

- 快速存取结构化数据
    
- 不想用商业数据库（太贵）
    
- 不满意 mSQL（功能不足）
    

于是：

- 自己写了一个 ISAM 存储引擎
    
- 外面包了一层 SQL-like 接口
    
- 这就是最早的 MySQL
    

> MySQL = **My + SQL**  
> “My” 是他女儿的名字（不是 “my” 的意思）

## 三、后来逐步加入了哪些语言？

这是个**渐进式演化**的过程，不是一次性重构。

### 🧱 1. C（一直是主干）

- Server core
    
- Optimizer
    
- Storage Engine 接口
    
- 内存、线程、锁
    

> **C 是 MySQL 的骨架**

---

### 🧩 2. C++（逐步引入）

随着系统复杂度上升，引入了部分 C++：

- 类封装（如 handler / engine 抽象）
    
- STL（后来谨慎使用）
    
- RAII 管理资源（有限）
    

⚠️ 但注意：

> **MySQL 不是“现代 C++ 项目”**  
> 它是 _C with some C++ features_

---

### 🔌 3. SQL Parser：yacc / bison（不是语言，但很关键）

- SQL 语法是用 **YACC/Bison + Lex/Flex** 生成的
    
- Parser 非常古老、非常硬核
    
- 你要是看过源码，大概率会说一句：
    
    > _What the hell is this…_
    

---

### 🐍 4. 外围工具 & 脚本语言

不是 Server 核心，但很重要：

- **Perl**（早期测试、构建）
    
- **Python**（后来测试框架）
    
- **Shell**（构建、部署）
    
- **Java**
    
    - JDBC Driver（MySQL Connector/J）
        
    - 但 **Server 本身不是 Java**
        

---

### 🌐 5. 客户端 & 生态语言（非核心）

- C / C++
    
- Java
    
- PHP（🔥 MySQL 能火，PHP 功不可没）
    
- Python
    
- Go（后来社区）
    

---

## 四、存储引擎时代：架构上的一次大转折

### 🧠 这是 MySQL 历史上最重要的一次设计决策

**MySQL 3.x / 4.x**

- 存储引擎是“写死的”（MyISAM）
    

**MySQL 5.0 之后**

- 引入 **Pluggable Storage Engine**
    
- InnoDB / MyISAM / Memory / NDB …
    

👉 技术影响极大：

- SQL 层（Parser / Optimizer）
    
- 存储层（事务 / 锁 / MVCC）解耦
    

你现在学 InnoDB、Buffer Pool、Redo Log，  
**就是这个时期奠定的架构。**

## 五、从“社区项目”到“商业数据库”的转变

这是你问题里**最有深度的一部分** 👀

### 阶段一：纯社区 & 开源（1995–2000）

- 完全开源
    
- GPL 协议
    
- 小而美，工程师导向
    

---

### 阶段二：双授权模式（2001–2008）

成立 **MySQL AB**：

- **GPL**：给社区
    
- **Commercial License**：卖给不想 GPL 的公司
    

这是一个非常聪明的商业模式：

> _Open Core + Commercial Support_

---

### 阶段三：被 Sun 收购（2008）

- Sun Microsystems 收购 MySQL
    
- 目标：对抗 Oracle DB
    

但 Sun 自身开始走下坡路 😐

---

### 阶段四：Oracle 收购 Sun（2010）⚠️

**重大转折点**

Oracle：

- 拥有世界第一的商业数据库
    
- 又“被迫”拥有 MySQL
    

社区的担忧：

- MySQL 会不会被“雪藏”？
    
- 会不会故意限制功能？
    

---

## 六、社区分裂：MariaDB 的诞生

Monty 的反应很直接：

> **Fork MySQL → MariaDB**

### MariaDB：

- 核心开发者就是原 MySQL 团队
    
- 更激进地引入新特性
    
- 完全社区导向
    

今天的现实：

- MySQL：**稳定、保守、企业友好**
    
- MariaDB：**社区、性能、创新更快**
    

---

## 七、一句话总结（给你一个“面试级”答案）

> **MySQL 最初由 C 编写，核心至今仍以 C 为主，后期引入少量 C++ 用于抽象与工程化；SQL 解析依赖 yacc/bison。它从一个工程师自用的社区项目，经历双授权商业化，被 Sun 收购后又随 Sun 进入 Oracle 体系，引发社区分裂，最终形成 MySQL（商业稳态）与 MariaDB（社区激进）并存的格局。**
